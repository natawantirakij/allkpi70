คำแนะนำการนำ Dashboard ไปเปิดให้คนทั่วไปใช้งานออนไลน์ฟรี

1. การเพิ่มข้อมูลหน่วยงานอื่น ๆ เข้ามาในหน้าเว็บนี้

เมื่อดึงข้อมูลหน่วยงานอื่นเป็นไฟล์ Excel/CSV ที่มี 10 คอลัมน์มาตรฐานเดียวกันแล้ว คุณสามารถกดปุ่ม "นำเข้า CSV หน่วยงานเพิ่ม" ที่มุมขวาบนของหน้าเว็บนี้ ระบบจะอ่านข้อมูลและเพิ่มหน่วยงานใหม่เข้าไปใน Dropdown ตัวกรองทันที

2. วิธีแชร์เป็นเว็บไซต์สาธารณะฟรี (Static Web Hosting)

  • วิธีที่ง่ายที่สุด (Netlify Drop): ดาวน์โหลดไฟล์โค้ด index.html นี้ลงเครื่อง แล้วลากไฟล์ไปวางที่เว็บ app.netlify.com/drop จะได้ลิงก์เว็บไซต์สาธารณะส่งให้ทุกคนเปิดดูได้ทันทีทั้งบนมือถือและคอมพิวเตอร์
  • GitHub Pages / Vercel: อัปโหลดไฟล์เดียวนี้ขึ้น GitHub Repository แล้วเปิดฟีเจอร์ GitHub Pages ฟรีตลอดชีพ ไม่มีค่าเซิร์ฟเวอร์เพราะข้อมูลฝังอยู่ในไฟล์แล้ว

3. การเชื่อมต่อกับ Google Looker Studio

หากต้องการทำกราฟเปรียบเทียบข้ามกระทรวงแบบ Drag & Drop คุณสามารถกดปุ่ม "ดาวน์โหลด Excel (CSV)" จากหน้านี้ แล้วนำไปอัปโหลดขึ้น Google Sheets เพื่อเชื่อมต่อไปยัง Looker Studio ได้ทันที
